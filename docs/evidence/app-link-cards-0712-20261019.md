## Card inventory and local behavior

These are application links embedded in Markdown text. They are distinct from existing approval, handoff, form and attachment transcript cards.

| Family | Example | Local action |
| --- | --- | --- |
| Right pane | `sand://app/v1/sidebar?tab=computer` | Open this message owner's Computer tab |
| Settings | `sand://app/v1/settings?id=computers` | Open global Computer settings |
| Bot | `sand://app/v1/agent?id=BOT_ID` | Select an existing Bot |
| Routine | `sand://app/v1/sidebar?automation=ROUTINE_ID&agent=BOT_ID&tab=routines` | Open the existing owner's routine detail |
| Plugin | `sand://app/v1/plugin/add?id=PLUGIN_ID` | Open native plugin details; does not install |
| Bot template | `sand://app/v1/bot-template?id=SHARE_ID` | Open the existing template preview; does not import |
| Task / thread | `sand://app/v1/task?id=0123456789` | Open only when the current local transcript resolves the target |

The supported right-pane destinations are overview, routines, media/Library and computer. Meeting/member-only panes, webhook field targets, missing Bots and unresolved tasks remain text because the corresponding 0.71.2 contracts are not available in this local renderer. Settings anchors open their existing section; unavailable cloud/account rows are not created. Plugin/template preview titles retain the supplied label until their native detail view resolves metadata. `grokbot://` and the local `groknode://` alias are also accepted inside chat.

The parser checks authority, route, identifiers, declared parameter order, duplicate/unknown parameters, credentials, port, fragment, encoding and maximum length. The Markdown URL transform preserves only valid app links. Activation stays inside Grok Node; it never dispatches these internal links to macOS's official-app URL handler.

## Implementation and checks

The build injects a React chip and the existing native hover-card primitive into the Markdown anchor renderer. Clicking the chip or preview footer runs the same action. Enter/Space use native button activation. Right-pane navigation uses the original owner-scoped request and stores the requested tab before a delayed pane mount. The template bridge reuses the existing preview and its cleanup. The host prompt and `/home/box/reference/app-ui.md` teach the Bot to send links rather than substituting screenshots.
