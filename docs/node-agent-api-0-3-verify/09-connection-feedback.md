# 网页连接反馈修复（2026-10-07）

用户报告 18770 点击“连接”没有反应。当前运行服务的 /health、带实际 owner 密钥的 /v1/capabilities、/v1/agents、/v1/models 均为 200；实际浏览器使用裸密钥成功加载 16 个 bot。因此未能证明用户当时具体的密钥或页面加载状态有误，也没有更换密钥。

已复现的反馈缺陷：无效测试密钥返回 401，错误只显示在中间栏，密钥框旁没有状态；连接期间也缺少就地进度提示。另有独立回归证明粘贴 Bearer 前缀会生成重复前缀，客户端的只读请求没有有界等待。

修复后在密钥框下显示连接进度、成功与中文失败提示，连接按钮显示“连接中…”；允许裸密钥和 Bearer 前缀输入，只发送单个前缀；只读 JSON 请求 30 秒超时且不重试。POST 等写操作和 SSE 不应用该超时，以保持接受状态与任务完成状态的原有区别。不会展示或持久化密钥。

真实浏览器验证：无效密钥显示“访问密钥无效或已过期”，带 Bearer 前缀的真实密钥成功，机器人列表 16 条，输入框清空，默认模型仍为空。新增回归覆盖前缀、超时、网络故障和取消。不宣称捕获了用户原页面的控制台错误。
